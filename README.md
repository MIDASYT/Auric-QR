# Auric QR — sitio público oficial

Sitio de descarga: https://midasyt.github.io/Auric-QR/ . Guía de instalación: https://midasyt.github.io/Auric-QR/instalar.html .

Este repositorio **público** contiene los archivos necesarios para presentar Auric QR mediante GitHub Pages: `index.html`, `instalar.html`, `style.css`, `assets/` y sus workflows públicos de QA. El código fuente de las aplicaciones de Windows y Android se mantiene fuera de esta web.

Las descargas instalables se habilitan únicamente cuando hay un EXE o APK oficial en GitHub Releases de `MIDASYT/Auric-QR`. El instalador de Windows no es el código fuente de la aplicación; el APK Android continúa sujeto a publicación y pruebas.

La interfaz visual adopta el diseño oficial de la familia, cuya referencia es AuricTurrets. Las webs AuricAI y AuricCode se publican en Firebase Hosting (no en sus repositorios de trabajo privados), mientras que Auric QR mantiene GitHub Pages.

Para informar de errores, indica sistema operativo, versión instalada y mensaje de instalación; nunca compartas contraseñas ni credenciales.
